---
title: "钩子管理"
description: "使用钩子在 Tram 的特定事件发生时执行自定义脚本，实现工作流自动化。"
---

Hooks 让你可以在 Tram 的关键事件上挂载脚本。它们适合做日志、通知、自动测试、权限审计和流程编排。

## 你可以控制什么

在配置里，Hooks 使用这些事件名：

- `UserPromptSubmit`
- `Stop`
- `Notification`
- `PreToolUse`
- `PostToolUse`
- `PostToolUseFailure`
- `SessionStart`
- `SessionEnd`
- `PreCompact`
- `SubagentStart`
- `SubagentStop`
- `PermissionRequest`

## 每个 hook 定义里能写什么

一个 hook 事件通常包含这些字段：

- `matcher`：只在匹配到特定条件时执行。
- `sequential`：是否按顺序串行执行。
- `hooks`：要执行的命令列表。

每个命令项可以写：

- `type: command`
- `command`
- `name`
- `description`
- `timeout`
- `env`

## 交互模式里的管理入口

在会话里输入 `/hooks` 可以打开管理界面。交互模式下你可以查看、添加、编辑或禁用 Hooks。

在非交互模式下，`/hooks` 会直接列出当前配置的 Hooks，方便你确认配置有没有生效。

## 一个最小示例

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "ShellTool",
        "sequential": true,
        "hooks": [
          {
            "type": "command",
            "name": "log-shell-use",
            "command": "node scripts/log-hook.js",
            "timeout": 5000
          }
        ]
      }
    ]
  }
}
```

## 需要注意什么

Hooks 会以你的用户权限运行，所以它们本质上就是本地自动化脚本。请只放可信命令，并确保脚本不会阻塞 Tram 太久。

<Tip>
  如果你只是想暂时关闭所有 Hooks，不要删配置，直接用 `disableAllHooks` 即可。
</Tip>

<Note>
  长时间运行的 hook 会拖慢 Tram 的响应。能快速返回的脚本更适合挂到 Hooks 上。
</Note>

钩子（Hooks）允许你在 Tram 的特定事件发生时执行自定义脚本，实现工作流自动化。

## 什么是钩子

钩子是 Tram 在特定事件时触发的脚本或命令。你可以使用钩子来：

- 在任务开始前执行预处理
- 在任务完成后执行后处理
- 发送通知或记录日志
- 集成到 CI/CD 流程

## 可用的钩子事件

Tram 支持以下钩子事件：

- **beforeTask** — 在智能体开始处理任务前触发
- **afterTask** — 在智能体完成任务后触发
- **beforeSession** — 在会话开始前触发
- **afterSession** — 在会话结束后触发

## 在交互模式中使用钩子

在交互模式中，使用 `/hooks` 命令来管理钩子：

```
/hooks
```

这会打开钩子管理界面，你可以：

- 查看已配置的钩子
- 添加新的钩子
- 编辑现有钩子
- 启用/禁用钩子

## 钩子脚本示例

钩子脚本可以是任何可执行文件。以下是一些示例：

### Shell 脚本钩子

```bash
#!/bin/bash
# afterTask.sh - 任务完成后执行
echo "Task completed at $(date)" >> /tmp/tram.log
```

### Node.js 脚本钩子

```javascript
// beforeTask.js
const fs = require('fs');
console.log('Starting task...');
// 执行预处理逻辑
```

## 配置钩子

钩子配置存储在 Tram 的配置文件中。每个钩子需要指定：

- **事件名称** — 触发钩子的事件
- **命令** — 要执行的命令或脚本
- **工作目录** — 执行命令的目录（可选）
- **环境变量** — 传递给命令的环境变量（可选）

## 使用建议

- **日志记录** — 使用钩子记录任务执行历史
- **通知** — 在长时间任务完成时发送通知
- **自动化测试** — 在代码生成后自动运行测试
- **部署** — 在任务完成后触发部署流程

<Tip>
  钩子脚本应该快速执行并返回正确的退出码。长时间运行的钩子可能会阻塞 Tram 的执行。
</Tip>

<Note>
  钩子脚本会以你的用户权限执行。请确保脚本来源可信，并且不会执行危险操作。
</Note>

无头模式适合脚本、CI 和一次性任务。你把提示直接传给 Tram，Tram 处理完后把结果写到标准输出并退出。

## 语法

```bash
tram -p "你的提示"
```

## 你可以拿它做什么

无头模式很适合这些场景：

- 生成测试、README、迁移说明或重构建议。
- 在 CI 里生成发布摘要。
- 把 Tram 的输出继续交给其他命令处理。
- 在脚本里保存结果，或把结果重定向到文件。

```bash
tram -p "Explain the main entry point of this project"
tram -p "List all exported functions in src/index.ts"
tram -p "Summarize the recent changes in CHANGELOG.md"
```

## 常见组合方式

```bash
tram -p "Summarize the changes in CHANGELOG.md" > release-notes.txt
tram -p "List all TODO comments in the src/ directory" | grep "FIXME"
tram -p "Write a README for the src/utils/ module" > src/utils/README.md
```

如果你希望脚本拿到结构化结果，可以把 `output.format` 设为 `json`。这样更适合自动化管道和后续解析。

## 和交互模式的区别

无头模式不会打开会话界面，也不适合需要你当场选择结果的流程，比如 Arena 的对比和选中结果。那些场景请继续使用交互模式。

## 退出行为

Tram 任务完成后会直接退出。成功时退出码通常为 `0`，这让你可以很方便地在 shell 里串联命令。

<Note>
  无头模式仍然依赖你已经完成认证。先用交互模式运行一次 `tram` 并完成登录，然后再在脚本里使用 `-p`。
</Note>

交互模式是 Tram 的主操作界面。运行 `tram` 后，你会进入一个持续会话，可以直接提问、切换模型、管理集成，并把文件路径作为上下文传给 Tram。

## 启动会话

在项目根目录运行：

```bash
tram
```

首次启动时，Tram 会引导你完成认证和初始配置。之后再次运行时，会直接进入会话。

## 你可以直接控制的内容

在提示符里，你可以做这些事：

- 直接提问，比如解释代码、追踪数据流、总结模块职责。
- 用 `@路径` 附加文件或目录，例如 `@src/app.ts` 或 `@src/services`。
- 输入 `/model` 切换当前会话的模型，或用 `/model --fast <模型>` 设置快速模型。
- 输入 `/auth` 重新打开认证向导。
- 输入 `/mcp` 管理 MCP 服务器。
- 输入 `/extensions` 管理扩展。
- 输入 `/hooks` 管理 Hooks。
- 输入 `/arena` 启动多模型对战、查看状态、选择结果。
- 输入 `/help` 查看内置帮助。

## `@路径` 的用法

`@` 语法是 Tram 里最直接的上下文控制方式。你可以把文件或目录直接放进问题里，Tram 会读取它们并把内容一起送入模型。

```text
解释 @src/index.ts 和 @src/config/ 之间的数据流。
```

几个实用规则：

1. 你只能引用工作区内的路径，或者项目临时目录里的路径。
2. `@` 读取会受 `.gitignore` 和 `.tramignore` 影响，具体取决于你的设置。
3. 路径里有空格时，可以用反斜杠转义。

## 常用会话命令

```text
/model
/model --fast qwen3-coder-flash
/mcp
/extensions
/hooks
/arena start --models qwen3-coder,qwen3-coder-flash "refactor the auth flow"
/arena status
/arena select
/arena stop
```

## 退出会话

输入 `exit` 或 `quit`，也可以按 `Ctrl+C` 返回 shell。

## 使用技巧

- 先把问题缩小到具体文件或函数，再让 Tram 展开解释。
- 对于大型仓库，先用 `@` 附上最相关的目录，再继续追问。
- 如果你要做重复性工作，先在交互模式里验证一次提示，再迁移到无头模式。

<Tip>
  从项目根目录运行 `tram`。这样 Tram 看到的上下文最完整，也最容易准确定位跨文件关系。
</Tip>

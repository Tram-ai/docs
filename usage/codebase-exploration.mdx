Tram 的代码库探索能力主要依赖两件事：当前工作目录，以及你在问题里主动附带的路径。你不需要手动复制文件内容，直接把路径写进提示里就行。

## 最直接的用法

```text
解释 @src/index.ts 的启动流程。
```

```text
比较 @src/server/ 和 @src/worker/ 的职责差异。
```

你也可以把目录直接附加进去，让 Tram 自动读取目录内容并结合上下文回答。

## 你可以控制什么

Tram 在读取代码时会遵循这些规则：

1. 只读取工作区里的路径，或者项目临时目录里的路径。
2. 默认会尊重 `.gitignore` 和 `.tramignore`，具体行为由配置决定。
3. 路径里有空格时可以用反斜杠转义。
4. 你可以一次提多个路径，Tram 会一起纳入上下文。

## 适合的提问方式

下面这些问题通常能得到更好的回答：

```text
Explain the overall structure of this project.
What does the UserService class do?
Where is the authentication logic handled?
Show me how data flows from the API to the database.
```

更好的做法是直接点名文件、函数或目录：

- `src/services/email.ts` 里发生了什么？
- `src/middleware/errors.ts` 是怎么处理错误的？
- `src/routes/` 下面哪个文件负责鉴权？

## 让结果更准的设置

如果你经常做代码阅读，可以在配置里把更多目录放进 `context.includeDirectories`。如果你不想让 Tram 读某些目录，可以继续用 `.gitignore`、`.tramignore` 和文件过滤设置控制。

<Tip>
  从项目根目录运行 `tram`，然后在提示里直接引用路径。这样 Tram 能看到最完整的上下文，尤其适合跨文件分析。
</Tip>

<Info>
  Tram 只会把你主动提供的上下文发送给模型提供商。它不会替你把整个仓库上传到任何地方。
</Info>

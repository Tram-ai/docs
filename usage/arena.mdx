---
title: "Arena 多智能体协作"
description: "使用 Arena 功能同时运行多个 AI 智能体，对比不同模型的结果，选择最佳方案。"
---

Arena 会让多个模型同时处理同一个任务，并把结果放到独立的 Git worktree 里。它适合你想对比不同实现、不同风格或不同提供商结果的时候。

## 你可以控制什么

最核心的命令是：

```text
/arena start --models qwen3-coder,qwen3-coder-flash "refactor the auth flow"
/arena start --models openai:gpt-4o,anthropic:claude-3 "implement sorting"
/arena status
/arena select
/arena select --discard
/arena stop
```

`/arena start` 至少要传两个模型。模型可以直接写成 `modelId`，也可以写成 `authType:modelId`。如果你不指定 `authType`，Arena 会使用当前会话的默认认证类型。

如果你只输入 `/arena` 或 `/arena start`，Tram 会打开交互式对话框，让你在 UI 里选择任务和模型。

## 结果怎么选

当 Arena 跑完后，你可以：

1. 用 `/arena status` 查看当前状态。
2. 用 `/arena select` 打开选择界面。
3. 直接输入 `/arena select <modelId>`，把某个成功结果应用回当前工作区。
4. 用 `/arena select --discard` 丢弃结果并清理 worktree。
5. 用 `/arena stop` 手动结束当前会话。

## Arena 的可调设置

你还可以在配置里控制 Arena 的行为：

- `agents.arena.worktreeBaseDir`：Arena worktree 的基础目录。
- `agents.arena.preserveArtifacts`：是否保留 worktree 和会话状态。
- `agents.arena.maxRoundsPerAgent`：每个智能体的最大轮次。
- `agents.arena.timeoutSeconds`：整个 Arena 会话的总超时。

## 适合的场景

- 你想比较多个模型对同一段代码的修改。
- 你想让不同模型生成不同方案，再从中选一个。
- 你希望在重要重构前先看多个答案，再决定方向。

<Tip>
  Arena 只适合交互模式。它需要你能看到 UI、对比结果并手动选择最终方案。
</Tip>

<Note>
  Arena 会比普通会话消耗更多资源，因为多个模型会同时工作。开始前先确认你的配额和运行时间预算。
</Note>

Arena 是 Tram 的高级功能，允许你同时运行多个 AI 智能体来处理同一个任务。每个智能体在独立的 Git worktree 环境中工作，你可以对比它们的结果并选择最佳方案。

## 什么是 Arena

Arena 通过以下方式帮助你获得更好的结果：

- **并行执行** — 多个智能体同时处理同一任务
- **环境隔离** — 每个智能体在独立的 Git worktree 中工作，互不干扰
- **结果对比** — 直观对比不同智能体的输出，选择最符合你需求的方案

## 启动 Arena 会话

在交互模式下，使用 `/arena` 命令启动 Arena 会话：

```
/arena 为这个项目生成一个 README 文件
```

Tram 会启动多个智能体，每个智能体使用不同的配置或模型来处理你的任务。

## Arena 工作原理

1. **任务分发** — Arena 管理器接收你的任务描述
2. **环境准备** — 为每个智能体创建独立的 Git worktree
3. **并行执行** — 多个智能体同时处理任务
4. **结果收集** — Arena 收集所有智能体的输出
5. **结果展示** — 你可以查看和对比各个智能体的结果

## Arena 事件

Arena 会发射以下事件，你可以在 UI 中观察进度：

- **会话开始** — Arena 会话已启动
- **智能体完成** — 单个智能体完成任务
- **会话结束** — 所有智能体完成工作

## 查看 Arena 状态

在交互模式中，Arena 会实时显示每个智能体的状态：

- **运行中** — 智能体正在处理任务
- **已完成** — 智能体成功完成任务
- **失败** — 智能体遇到错误

## 使用建议

- **复杂任务** — Arena 特别适合需要对比多种解决方案的复杂任务
- **代码生成** — 让多个智能体生成不同实现的代码，选择最佳版本
- **重构决策** — 对比不同的重构方案

<Tip>
  Arena 需要 Git 仓库才能正常工作，因为它使用 Git worktree 创建隔离环境。确保你的项目已初始化 Git 仓库。
</Tip>

<Note>
  Arena 功能需要消耗更多的 API 配额，因为多个智能体会同时处理任务。请注意你的 API 使用量。
</Note>

---
title: "扩展管理"
description: "使用扩展来增强 Tram 的功能，安装、管理和创建自定义扩展。"
---

扩展可以给 Tram 增加新命令、外部服务、工具和消息通道。只要你安装了扩展，Tram 就会把它提供的能力合并进当前会话。

## 你可以控制的命令

```bash
tram extensions list
tram extensions install <source>
tram extensions uninstall <name>
tram extensions update <name>
tram extensions update --all
tram extensions enable <name>
tram extensions disable <name>
tram extensions link <path>
tram extensions new <path> [template]
tram extensions settings list <name>
tram extensions settings set <name> <setting>
```

## 安装来源

`tram extensions install` 支持这些来源：

1. Git 仓库地址。
2. 本地路径。
3. scoped npm 包。
4. marketplace 扩展来源。

常见参数包括：

- `--ref`：指定 git ref。
- `--auto-update`：启用自动更新。
- `--pre-release`：允许预发布版本。
- `--registry`：指定 npm registry。
- `--consent`：跳过安装确认。

## 启用、禁用和作用域

`tram extensions enable` 和 `tram extensions disable` 都支持作用域控制。你可以按 `user` 或 `workspace` 处理某个扩展，而不是一次改掉所有地方。

## 本地开发

如果你在开发自己的扩展，可以先创建模板：

```bash
tram extensions new ./my-extension
tram extensions link ./my-extension
```

`new` 支持选择模板；`link` 会把本地目录链接进 Tram，方便你在改代码时立即测试。

## 扩展设置

`tram extensions settings list <name>` 会列出扩展可配置的项。`tram extensions settings set <name> <setting>` 可以设置单个值，并支持 `--scope user|workspace`。

## 在交互模式里使用

在会话里输入 `/extensions` 可以打开管理界面。你也可以用 `/extensions explore Gemini` 或 `/extensions explore ClaudeCode` 去看扩展市场。

## 扩展还能做什么

扩展不只会增加命令。它们还可以：

- 提供新的 MCP 服务器。
- 提供新的消息通道类型。
- 带来额外设置项和默认值。

<Tip>
  先用 `tram extensions list` 看清楚当前启用了什么，再决定是否更新、禁用或卸载。
</Tip>

<Note>
  只安装你信任的扩展。扩展可以访问项目文件、配置和网络能力，所以要像审核依赖一样审核它们。
</Note>

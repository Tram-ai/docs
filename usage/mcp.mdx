---
title: "MCP 服务器管理"
description: "使用 Model Context Protocol (MCP) 扩展 Tram 的能力，连接外部工具和数据源。"
---

MCP 让 Tram 可以连接外部工具和数据源。你可以把它理解成“给 Tram 增加新工具箱”的方式。

## 你可以控制的命令

```bash
tram mcp add <name> <commandOrUrl> [args...]
tram mcp list
tram mcp remove <name>
tram mcp reconnect <server-name>
tram mcp reconnect --all
```

`tram mcp add` 是最常用的入口。它支持三类接入方式：

1. `stdio`：传入一个启动命令。
2. `sse`：传入一个 SSE 地址。
3. `http`：传入一个 HTTP 地址。

如果你传的是 `http://` 或 `https://`，Tram 会自动按 HTTP 方式识别；你也可以用 `--transport` 显式指定。

## `tram mcp add` 的常用参数

```bash
tram mcp add filesystem "npx -y @modelcontextprotocol/server-filesystem /path/to/allowed/dir"
tram mcp add my-server https://example.com/mcp --transport http
```

可控参数包括：

- `--scope user|project`：决定写到用户配置还是项目配置。
- `--env KEY=value`：给 stdio 服务器注入环境变量。
- `-H "Header: value"`：给 SSE/HTTP 服务器加请求头。
- `--timeout`：连接超时。
- `--trust`：跳过工具调用确认。
- `--description`：给服务器加说明。
- `--include-tools` / `--exclude-tools`：按工具名筛选暴露范围。
- `--ref`、`--auto-update`、`--pre-release`、`--registry` 只在特定来源类型下有效。

如果你要给 stdio 命令传额外参数，可以把 `--` 后面的内容直接附给服务器命令。

## 列表和重连

`tram mcp list` 会显示每个服务器的连接状态。`tram mcp reconnect <server-name>` 可以重新发现某个服务器的工具，`tram mcp reconnect --all` 则会全部重连。

## 配置位置和作用域

MCP 服务器会保存到 Tram 的设置里。用户级配置适合全局复用，项目级配置适合只让当前仓库使用。

如果你删除了某个 MCP 服务器，Tram 也会尽量清理对应的 OAuth 凭证。

## 在交互模式里使用

在会话里输入 `/mcp` 可以直接打开管理界面。配置好以后，Tram 会自动把这些服务器提供的工具带进会话里。

<Tip>
  改完 MCP 配置后，通常重开一次会话最稳妥。这样可以确保新的工具定义已经被重新加载。
</Tip>

<Note>
  MCP 服务器会接触你的项目文件和外部服务。只连接你信任的服务器，并确认它们暴露出来的工具范围。
</Note>

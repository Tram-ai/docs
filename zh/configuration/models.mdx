Tram 使用你在设置期间提供的 API 密钥连接到 AI 模型提供商。首次运行 `tram` 时，你选择要使用的模型提供商，Tram 会将该选择存储在本地配置中。你可以随时通过重新运行设置提示来更改模型选择。

## 广泛的模型支持

Tram 基于 [Qwen Code](https://github.com/QwenLM/Qwen3-Coder) 和 [Gemini CLI](https://github.com/google-gemini/gemini-cli) 构建，因此广泛支持多种 AI 模型提供商。这意味着你不会被锁定在单一提供商——你可以将 Tram 配置为使用最适合你工作流和预算的模型。

## 在设置期间选择模型

首次运行 `tram` 时，设置提示会要求你选择模型提供商并提供相应的 API 密钥。按照提示完成选择。

```bash
tram
```

要切换到其他模型，再次运行 `tram` 并按照设置提示操作。Tram 会用新的模型选择更新你的已保存配置。

## 为你的任务选择合适的模型

不同的任务受益于不同的模型。使用以下指导来帮助你做出选择：

- **大型代码库探索** — 使用具有大上下文窗口的模型，这样 Tram 可以一次将更多代码库保持在上下文中。在处理多个文件时，这会产生更准确、更连贯的结果。
- **快速查询和单文件任务** — 较小、较快的模型响应更快且每次请求成本更低，适合有针对性的问题或简单编辑。
- **自动化管道** — 对于无头模式用例，优先考虑可靠性和速度，而非原始上下文大小。

<Tip>
  在探索大型代码库时，选择具有长上下文窗口的模型。较大的上下文窗口让 Tram 能够一次读取和推理更多文件，这显著提高了在大型项目中解释、总结和重构建议的质量。
</Tip>

<Note>
  Tram 不会代你承担 API 使用费用。你需要为所选模型提供商产生的任何费用负责。在运行大型或长时间任务之前，请查看提供商的定价。
</Note>

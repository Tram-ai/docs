Tram 在初始设置后将配置存储在本地计算机上，因此你不需要每次运行时都重新配置。首次启动 Tram 时，它会引导你完成一个简短的设置过程，在此过程中你需要提供 API 密钥并选择模型提供商。此后，Tram 每次启动时都会自动读取已保存的配置。

## 初始设置

首次运行 `tram` 时，它会检测到没有配置存在，并启动交互式设置提示。按照提示提供你的 API 密钥并选择模型提供商。设置大约需要 30 秒。

```bash
tram
```

设置完成后，Tram 会将配置保存到你计算机的标准用户配置目录中。除非你想更改设置，否则不需要再次运行设置。

## 配置内容

在设置过程中，Tram 收集并存储以下信息：

- **API 密钥** — 用于向所选 AI 模型提供商进行身份验证的密钥
- **模型提供商** — 你希望 Tram 连接的 AI 服务
- **会话偏好** — 影响 Tram 在会话期间行为的默认设置

## 更新配置

要更改 API 密钥、切换模型提供商或更新会话偏好，重新运行 `tram` 并再次按照设置提示操作。Tram 会用你提供的新值覆盖现有配置。

```bash
tram
```

如果你更喜欢直接编辑配置文件，可以在操作系统的标准用户配置目录中找到它（例如，在 Linux 和 macOS 上为 `~/.config/tram/`）。

<Note>
  Tram 不会将你的配置发送到任何 Tram 服务器。你的 API 密钥和偏好仅存储在本地计算机上，只有在你发出请求时才会直接传输到你选择的 AI 模型提供商。
</Note>

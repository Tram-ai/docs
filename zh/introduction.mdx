Tram 是一个开源的 AI 智能助手，直接在你的终端中运行。你只需通过 npm 全局安装一次，将其指向一个项目目录，然后通过实时会话或单行命令与它交互。Tram 使用你的 API 密钥连接到 AI 模型，在你最常使用的环境——终端中与你协同工作。

## Tram 能做什么

Tram 旨在通过提供一个理解你项目的智能助手来加速软件开发。你可以用它来：

- **理解大型代码库** — 让 Tram 解释陌生的文件、追踪某个功能的工作原理，或总结你刚刚接手的项目结构
- **自动化重复的开发任务** — 将编写样板代码、跨文件重构模式或生成文档等工作委派给它
- **加速开发** — 无需离开终端或切换到浏览器，即可获取答案和可用代码

## 工作原理

运行 `tram` 以打开交互式会话，或使用 `-p` 标志直接传递提示：

```bash
tram -p "Explain this project's structure"
```

首次运行时，Tram 会引导你完成简短的配置以设置 API 密钥。此后，每次会话都会自动连接到你选择的 AI 模型提供商，并在终端中开始协助你。

## 系统要求

在安装 Tram 之前，请确认你具备以下条件：

- **Node.js 20 或更高版本** — Tram 需要 Node.js 20+。运行 `node --version` 检查版本。
- **npm** — 随 Node.js 一起提供，用于全局安装 Tram CLI。

## 开源血统

Tram 基于以下两个优秀的开源项目构建并致谢：

- [Qwen Code](https://github.com/QwenLM/Qwen3-Coder)，由阿里巴巴 Qwen 团队开发
- [Gemini CLI](https://github.com/google-gemini/gemini-cli)，由 Google 开发

Tram 修改并扩展了这些项目，以提供其终端原生的 AI 智能助手体验。

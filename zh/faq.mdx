以下是 Tram 用户经常提出的问题及其解答。如果你的问题未在此处涵盖，请访问 [Tram GitHub 仓库](https://github.com/Tram-ai/tram) 浏览已有问题或发起讨论。

<AccordionGroup>
  <Accordion title="Tram 是免费的吗？">
    是的——Tram CLI 本身是开源且免费安装和使用的。但是，Tram 会连接第三方 AI 模型提供商来处理你的请求，这些提供商会对 API 使用收费。你需要为所选提供商产生的任何费用负责。在运行大型或长时间任务之前，请查看提供商的定价。
  </Accordion>

  <Accordion title="Tram 会上传我的代码吗？">
    Tram 会将你的提示和相关代码上下文发送到你配置的 AI 模型提供商的 API 以生成响应。这些数据直接发送到你的提供商——而不是任何 Tram 服务器。Tram 本身不会存储、记录或保留你的任何代码或提示。请查看你的模型提供商的隐私政策，了解他们如何处理你发送的数据。
  </Accordion>

  <Accordion title="Tram 支持哪些 AI 模型？">
    Tram 基于 [Qwen Code](https://github.com/QwenLM/Qwen3-Coder) 和 [Gemini CLI](https://github.com/google-gemini/gemini-cli) 构建，因此广泛支持多种 AI 模型提供商。你在首次运行 `tram` 时进行初始设置，配置提供商和 API 密钥。要切换提供商，随时重新运行设置提示即可。
  </Accordion>

  <Accordion title="我可以在 CI/CD 管道中使用 Tram 吗？">
    可以。Tram 支持无头模式，允许你直接从命令行传递提示，而无需启动交互式会话。使用 `-p` 标志加上你的任务：

    ```bash
    tram -p "your task"
    ```

    在 CI/CD 环境中使用 Tram 时，请通过管道的密钥管理系统非交互式地配置 API 密钥，而不是依赖交互式设置提示。
  </Accordion>

  <Accordion title="我需要什么版本的 Node.js？">
    Tram 需要 Node.js 20 或更高版本。要检查当前版本，请运行：

    ```bash
    node --version
    ```

    如果你使用的是旧版本，请使用 [nvm](https://github.com/nvm-sh/nvm) 升级，或从 [nodejs.org](https://nodejs.org/) 下载最新的 LTS 版本。
  </Accordion>

  <Accordion title="Tram 是否已经可用于生产环境？">
    Tram 目前处于测试阶段。它正在积极开发中，适合日常使用，但你可能会遇到 bug 或版本之间的破坏性更改。在将 Tram 集成到关键工作流时请注意这一点，并定期更新以获取最新修复。如果遇到问题，请在 [GitHub 问题追踪器](https://github.com/Tram-ai/tram/issues) 上报告。
  </Accordion>

  <Accordion title="如何更新 Tram？">
    运行以下命令更新到最新版本：

    ```bash
    npm install -g @tram-ai/tram@latest
    ```

    这将用最新版本覆盖你的现有安装。你的本地配置会被保留。
  </Accordion>

  <Accordion title="如何卸载 Tram？">
    运行以下命令从系统中移除 Tram：

    ```bash
    npm uninstall -g @tram-ai/tram
    ```

    这将移除 `tram` 二进制文件。你的本地配置文件不会自动移除——如果你需要完全清除，请从用户配置文件夹中删除 Tram 配置目录。
  </Accordion>
</AccordionGroup>

Tram 的配置保存在本地，并且会在每次启动时自动读取。大部分设置都可以在 UI 里调整，少部分也可以通过命令行直接管理。

## 配置是如何生效的

Tram 会把用户级、工作区级和部分系统级设置合并起来使用。很多命令都支持显式指定作用域，例如 `user` 或 `workspace`，这样你可以决定某个配置是只影响当前项目，还是影响整台机器。

有些设置修改后会立即生效，有些设置会标记为需要重启。遇到这类选项时，重新启动 Tram 才会看到完整效果。

## 你能控制的内容

Tram 的设置按功能分组，常见的控制点包括：

- **模型**：主模型、快速模型、备用模型、会话轮次上限、上下文窗口、生成参数。
- **认证**：当前认证类型、API Key、Base URL、强制认证类型。
- **工具权限**：允许、询问或拒绝哪些工具和命令；是否自动接受安全操作；沙箱开关。
- **上下文**：要额外纳入的目录、文件过滤规则、空闲后清理上下文的策略。
- **UI**：主题、紧凑模式、提示文案、标题栏行为、无障碍选项、语言。
- **集成**：MCP 服务器、消息通道、Hooks、IDE 集成、Arena、多代理选项。
- **高级**：代理设置、运行目录、环境变量、遥测、实验性功能。

## 重要配置项

以下几类设置最值得优先关注：

1. `model.name`、`fastModel` 和 `model.fallbacks` 决定 Tram 实际请求哪个模型。
2. `tools.approvalMode` 与 `permissions.allow/ask/deny` 决定哪些操作会自动执行，哪些需要你确认。
3. `context.fileFiltering.respectGitIgnore` 和 `context.fileFiltering.respectTramIgnore` 决定哪些文件会被纳入上下文。
4. `mcpServers`、`channels` 和 `hooks` 决定你接入哪些外部能力。
5. `agents.arena.*` 决定 Arena 的工作目录、保留策略和超时时间。

<Note>
  Tram 只会把你的配置用于本地会话和请求发送。配置不会上传到 Tram 服务器。
</Note>

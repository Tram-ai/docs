---
title: "Headless mode with -p flag for scripting"
description: "Run Tram non-interactively using the -p flag. Pass a prompt directly on the command line and get output you can pipe, redirect, or use inside shell scripts."
---

Headless mode lets you run Tram without starting an interactive session. Pass your prompt directly using the `-p` flag and Tram executes the task, prints the result to stdout, and exits. This makes it easy to use Tram inside shell scripts, CI pipelines, or anywhere you need a one-shot AI response from the command line.

## Syntax

```bash
tram -p "<your prompt>"
```

## Examples

```bash
tram -p "Explain the main entry point of this project"
tram -p "List all exported functions in src/index.ts"
tram -p "Summarize the recent changes in CHANGELOG.md"
```

## Use cases

**Shell aliases** — wrap common queries you run often:

```bash
alias explain-entry='tram -p "Explain the main entry point of this project"'
```

**CI scripts** — generate a summary as part of a pipeline step:

```bash
#!/bin/bash
tram -p "Summarize the changes in CHANGELOG.md" > release-notes.txt
```

**Piping output** — feed Tram's response into other tools:

```bash
tram -p "List all TODO comments in the src/ directory" | grep "FIXME"
```

**Output redirection** — save Tram's response to a file for later review:

```bash
tram -p "Write a README for the src/utils/ module" > src/utils/README.md
```

## Exit behavior

Tram exits as soon as the task is complete. The process exit code is `0` on success, which makes it straightforward to chain commands or check results in scripts:

```bash
tram -p "Check if there are any syntax errors in src/index.ts" && echo "Looks good"
```

<Note>
  Headless mode requires authentication to be configured before use. Authentication is set up on the first run of `tram` in interactive mode. Run `tram` once and follow the prompts, then you can use `-p` in any subsequent command or script.
</Note>

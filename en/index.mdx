## What you can do with Tram

Tram is designed to speed up software development by giving you an intelligent assistant that understands your project's code.

<Steps>
  <Step title="Install Tram">
    Install the CLI globally with a single npm command. Requires Node.js 20 or later.

    ```bash
    npm install -g @tram-ai/tram@latest
    ```
  </Step>
  <Step title="Configure your AI provider">
    On first run, Tram will prompt you to supply an API key for your chosen AI model provider. This takes about 30 seconds.

    ```bash
    tram
    ```
  </Step>
  <Step title="Start exploring">
    Ask Tram to explain a file, summarize a module, find a bug, or generate code — all from within your existing terminal workflow.
  </Step>
</Steps>

## 你可以用 Tram 做什么

Tram 旨在通过提供一个理解项目代码的智能助手来加速软件开发。

<Steps>
  <Step title="安装 Tram">
    使用一条 npm 命令全局安装 CLI。需要 Node.js 20 或更高版本。

    ```bash
    npm install -g @tram-ai/tram@latest
    ```
  </Step>
  <Step title="配置 AI 提供商">
    首次运行时，Tram 会提示你提供所选 AI 模型提供商的 API 密钥。这大约需要 30 秒。

    ```bash
    tram
    ```
  </Step>
  <Step title="开始探索">
    让 Tram 解释文件、总结模块、查找 bug 或生成代码——全部在现有终端工作流中完成。
  </Step>
</Steps>

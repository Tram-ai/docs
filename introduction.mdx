Tram is an open-source AI agent that runs directly in your terminal. You install it once globally via npm, point it at a project directory, and interact with it through a live session or a single one-line command. Tram connects to an AI model using your API key and works alongside you in the environment where you already spend most of your time — the terminal.

## What Tram does

Tram is designed to make software development faster by giving you an intelligent assistant that understands your project. You can use it to:

- **Understand large codebases** — ask Tram to explain unfamiliar files, trace how a feature works, or summarize the structure of a project you've just inherited
- **Automate repetitive dev tasks** — delegate work like writing boilerplate, refactoring patterns across files, or generating documentation
- **Accelerate development** — get answers and working code without leaving your terminal or switching to a browser

## How it works

Run `tram` to open an interactive session, or pass a prompt directly with the `-p` flag:

```bash
tram -p "Explain this project's structure"
```

On first run, Tram walks you through a short configuration to set up your API key. After that, every subsequent session connects automatically to your chosen AI model provider and begins assisting you in your terminal.

## Requirements

Before you install Tram, confirm you have the following:

- **Node.js 20 or later** — Tram requires Node.js 20+. Run `node --version` to check.
- **npm** — included with Node.js and used to install the Tram CLI globally.

## Open-source heritage

Tram is built on and acknowledges two excellent open-source projects:

- [Qwen Code](https://github.com/QwenLM/Qwen3-Coder) by Alibaba's Qwen team
- [Gemini CLI](https://github.com/google-gemini/gemini-cli) by Google

Tram modifies and extends these projects to deliver its terminal-native AI agent experience.

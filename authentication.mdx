Tram 需要你先完成认证，才能连接到模型提供商并开始对话。认证信息只保存在本地，你只需要在每台机器上配置一次。

## 你可以控制的认证入口

最常用的方式是直接运行 `tram`，让 Tram 在首次启动时引导你完成认证和初始配置：

```bash
tram
```

如果你想直接操作认证流程，可以使用这些命令：

```bash
tram auth
tram auth qwen-oauth
tram auth coding-plan --region china --key <your-api-key>
tram auth status
```

`tram auth` 会打开交互式认证向导。`tram auth qwen-oauth` 用于 Qwen OAuth 登录。`tram auth coding-plan` 用于阿里云 Coding Plan 认证，`--region` 支持 `china` 或 `global`，`--key` 可以直接传入 API Key；如果你不传参数，Tram 会继续以交互方式询问。

`tram auth status` 会显示当前保存的认证状态，适合你确认当前到底在使用哪种认证方式。

<Warning>
  你的 API Key 能直接访问对应的模型服务。不要把密钥提交到版本控制，也不要在聊天中分享。把它当作密码处理。
</Warning>

## 认证信息保存在哪里

Tram 会把认证结果保存到本地配置目录中的用户设置里。后续启动时，Tram 会自动读取这些信息，不会每次都要求你重新登录。

如果你更换了机器、撤销了密钥，或者切换了提供商，重新运行 `tram auth` 或 `tram auth coding-plan` 即可更新本地保存的认证信息。

## 什么时候需要重新认证

以下情况通常意味着你需要重新认证：

1. API Key 被撤销、过期，或者配额不足。
2. 你从一个认证方式切换到了另一个，例如从 OAuth 切换到 Coding Plan。
3. 你希望在另一台机器上使用同一个 Tram 账号。

<Tip>
  如果你只是想确认当前状态，而不是修改配置，优先用 `tram auth status`。它比重新走一次认证流程更快。
</Tip>

Tram 代表你连接到 AI 模型提供商，因此需要一个有效的 API 密钥才能正常工作。你只需在初始配置提示时提供一次密钥，Tram 会将其存储在本地，以便在后续会话中无需再次输入。

## 身份验证的工作原理

当你首次运行 `tram` 时，Tram 检测到没有配置密钥，并在打开会话之前启动交互式设置提示。提示会要求你输入所选 AI 模型提供商的 API 密钥。提交后，Tram 将密钥存储在本地计算机上，并从此自动使用它。

<Warning>
  你的 API 密钥授予对付费 AI 模型提供商账户的访问权限。切勿将 API 密钥提交到版本控制、在聊天中分享，或包含在公开可见的配置文件中。请像对待密码一样对待它。
</Warning>

## 配置 API 密钥

运行 Tram 并按照提示操作：

```bash
tram
```

当配置提示出现时，粘贴你的 API 密钥并按回车。Tram 确认密钥已保存，然后打开你的会话。

<Tip>
  从你的 AI 模型提供商的开发者仪表板或 API 设置页面生成 API 密钥。大多数提供商只在创建时显示一次密钥——在关闭页面之前复制它，并将其存储在安全的地方。
</Tip>

## 密钥存储位置

Tram 将你的 API 密钥保存在本地计算机上。除了在发送请求时传输到 AI 模型提供商外，密钥不会被传输到任何其他地方。密钥会跨会话持久保存，因此你只需在每台计算机上配置一次。

## 支持的提供商

Tram 基于 [Qwen Code](https://github.com/QwenLM/Qwen3-Coder) 和 [Gemini CLI](https://github.com/google-gemini/gemini-cli) 构建，两者都支持 AI 模型提供商。请参阅 Tram 配置文档或设置提示本身以获取当前支持的提供商列表。

## 身份验证失败时的处理

如果 Tram 无法验证身份或你需要更新密钥，请通过启动新会话重新运行配置：

```bash
tram
```

如果你的密钥已存储但无效，Tram 会在尝试连接提供商时显示身份验证错误。在这种情况下：

1. 验证密钥是否正确，且未过期或被撤销。
2. 检查提供商的仪表板，确认密钥处于活动状态且有足够的配额。
3. 重新运行 `tram`，并在提示时输入新密钥。
